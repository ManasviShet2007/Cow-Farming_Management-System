# 🐄 Cow Farm Management System

## 📌 About the Project
The Cow Farm Management System is a web-based application designed to simplify and manage daily dairy farm activities. It helps farmers maintain records of cows, milk production, breeding, feeding, expenses, sales, health records, and veterinarians in one place.

## ✨ Features
- **Dashboard:** Overview of important farm activities.
- **Cow Management:** Maintain cow details and records.
- **Breeding Management:** Track breeding information.
- **Feeding Management:** Manage feeding schedules and records.
- **Milk Production:** Record daily milk production.
- **Milk Sales:** Maintain milk sales details.
- **Expense Management:** Track farm expenses.
- **Health Records:** Maintain cow health information.
- **Veterinarian Management:** Store veterinarian details.
- **Reports:** View farm management information.

## 🚀 How to Run
1. Install Java and MySQL.
2. Create the `cow_farm_db` database.
3. Execute the provided SQL scripts.
4. Configure your database connection.
5. Compile the Java backend.
6. Start the Java server.
7. Open `index.html` in your browser.

## 🎯 Project Objective
To make dairy farm management easier, more organized, and efficient through a digital platform.
